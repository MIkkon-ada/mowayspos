# 本地 V2 立项前端视觉改版验收

## 实际改动

- 新建立项弹窗由三个等宽窄列改为信息主区与团队侧栏，基本信息和目标分区，顶部标明草稿、下发、计划、审核四个阶段。
- 项目类型、名称、日期与说明使用统一字段尺寸和间距，团队空状态可直接点击选人。下拉及展开箭头复用 ChevronDownIcon。
- 负责人工作区采用深蓝主色、灰白画布、统一边框和按钮。工作目录编号并显示任务数量；目标和标准允许多行输入。
- 关键任务由挤在单行的表格编辑改为分组卡片：名称、人员、开始与结束日期、评价指标分别排列。保留原有表格语义及业务字段。
- 项目概览、完整方案预览和审核材料采用统一视觉规范。项目中心的状态统计压缩成一条，项目标题恢复自然排列。
- 新建成功后及时获取团队成员，避免列表错误显示企业教练未配置。
- 清理 styles.css 中反复覆盖的旧立项视觉层，专用样式集中到 projectInitiation.css。未调整包体积预算。
