# 本地 V2 立项前端改版

用户要求直接完善排版、布局和配色。由当前主智能体执行，不委派，不提交或上线。

设计方向：借鉴 Linear 项目概览的属性组织方式，使用深蓝主色、灰白画布、统一边框和文字层级。立项弹窗为宽内容区加团队侧栏；负责人页面使用精简项目摘要、工作目录、分组任务编辑；审核预览延续同一视觉规范。业务 API、草稿恢复和身份规则沿用现有实现。

- [x] 新建项目：替换三等分列，基本信息和目标上下组织，团队放右栏，显示立项步骤。
- [x] 方案编辑：精简摘要、编号工作目录、目标标准编辑、任务卡片和固定操作栏。
- [x] 项目入口和审核：压缩统计区，统一颜色、按钮、预览和标题。
- [x] 浏览器检查桌面与窄屏，验证保存恢复、预览、人员选择；原有工作切换单元测试通过。
- [x] 前端测试、类型检查和构建，保存真实页面截图。

结果：170 单元测试和 523 契约测试通过；构建及原有包体积预算通过。浏览器走过草稿创建至审核退回再编辑。详见 docs/acceptance/2026-10-12-initiation-visual-redesign.md。
