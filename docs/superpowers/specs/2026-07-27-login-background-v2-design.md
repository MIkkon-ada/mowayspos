# 登录页左侧背景 V2 设计

## 目标

以用户提供的 1672×943 登录视觉图作为左侧及底部的主背景，消除现有独立 MOWAYS 标识产生的拼贴感。

## 视觉实现

- 将用户图片无损编辑为一张无文字底图：仅移除图片内烘焙的主标题、副标题和蓝色短线。
- 保留 3D 蓝白平台、三枚功能图标、城市轮廓、底部数据网格及两侧波纹的构图、位置、光影和色调。
- 由页面 HTML 在同一留白区叠加“项目管理协同平台”、副标题和蓝色短线；文字可随桌面与窄屏布局响应式调整。
- 移除左侧独立的大型 MOWAYS Logo；不在该视觉区域以图片块、水印或临时标识的形式重新引入。
- 右侧现有登录卡、账号密码登录、忘记密码、密码可见性切换、企业微信登录和服务协议保持不变。

## 验收标准

- 桌面 1920×1080 时，背景与左侧文字融为一个完整场景，右侧登录卡不遮挡核心 3D 插画。
- 底图中不存在可见的旧标题、副标题和蓝色短线残留。
- 新叠加文字保持清晰、可访问，且在小于 1180px 的布局中遵循既有的表单优先策略。
- 页面不再显示左上角独立 MOWAYS Logo。
