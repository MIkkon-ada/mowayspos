# 登录页 Logo 位置 V3 设计

## 目标

在已确认的无文字插画底图上恢复正式 MOWAYS 品牌标识，同时避免出现白底图片块或临时拼贴感。

## 视觉实现

- 使用仓库内的正式 Logo 资产作为网页叠加元素，不将 Logo 烘焙进背景图片。
- Logo 位于桌面左上角，宽度约 160px，距页面左、上各约 80px，并与主标题左边缘对齐。
- Logo 不使用卡片、描边、阴影、背景色或额外装饰；若资产自身白底影响画面，应以 CSS 的视觉融合方式消除白底感。
- 保持主标题、副标题、蓝色短线、背景插画、功能卖点与右侧登录卡现有位置和行为不变。
- 在小于 1180px 的表单优先布局中，Logo 与左侧场景一起隐藏。

## 验收标准

- 1920×1080 下 Logo 是左上区域清晰但不抢占标题的正式品牌标识。
- Logo 与标题同左边缘，整体不呈现为独立图片块。
- 移动端保持无 Logo 的干净表单布局。
