# 登录页视觉焕新设计

## 目标

以 1920 × 1080 的桌面端为主要验收基准，重做登录页的视觉呈现，同时完整保留现有账号密码登录、企业微信登录/绑定、错误反馈与密码显示切换行为。

## 资源与边界

- 正式 Logo：`frontend/public/reference-login.png`。
- 3D 主视觉：用户本轮提供的 PNG 原图；实现时复制至前端公共资源目录，并以 `<img>` 使用。
- 不改动认证接口、会话逻辑、企业微信 OAuth 流程或表单字段语义。
- 桌面端以 1920 × 1080 为主，并兼容 1536 × 1024；小于约 1180px 时隐藏品牌/插画区，仅保留居中的登录表单。

## 页面结构

页面采用两栏布局：

1. 左侧品牌区：正式 Logo、标题“项目管理协同平台”、副标题、蓝色短横线、3D 插画，以及“安全可靠 / 高效协同 / 数据驱动”三项卖点。
2. 右侧登录区：白色圆角卡片，包含欢迎标题、说明、账号与密码字段、忘记密码入口、主登录按钮、分隔线、企业微信入口及合规提示。

右侧卡片在桌面端控制在约 560–600px 宽，使用浅阴影和较大圆角；左侧插画使用原图，以 `object-fit: contain` 保留完整构图，并让它在卡片与卖点之间占据主要视觉面积。

## 视觉规则

- 背景采用低对比度的蓝白渐变、淡蓝点阵与底部柔和波纹，不把纹理置于表单可读区域之上。
- 主色为饱和蓝；主按钮使用横向蓝色渐变，企业微信按钮保持白底绿色描边。
- 使用深蓝标题、灰蓝辅助文字与浅灰描边，确保和目标图相近的层次与阅读对比度。
- Logo 直接使用正式 PNG，不再依赖请求失败后的文字回退作为常规展示。

## 状态与可访问性

- 现有加载、禁用、错误、企业微信回调错误、企业微信未绑定账户绑定表单均保持可用。
- 输入框的标签、自动填充属性、密码可见性按钮与键盘提交行为保持不变。
- 移动端不加载或展示造成拥挤的左侧品牌区，保证表单在首屏可读、可操作。

## 验收标准

1. 1920 × 1080 下，Logo、左侧标题/插画/卖点和右侧白色登录卡的位置及视觉层级与效果图一致；在 1536 × 1024 下保持完整、比例协调的双栏布局。
2. 正式 Logo 和 3D 插画均从公共资源正确加载，无破图或常规回退 Logo。
3. 账号密码登录、密码显示切换、企业微信登录按钮、忘记密码提示与错误状态均不回归。
4. 1180px 以下不出现横向滚动，且登录表单仍可完整使用。
5. 前端类型检查与生产构建通过；更新后的页面使用本地截图在桌面与移动尺寸复核。
