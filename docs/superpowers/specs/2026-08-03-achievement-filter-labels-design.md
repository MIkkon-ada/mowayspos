# 成果库筛选栏清晰化设计

## 目标

让成果库顶部筛选条件无需依赖位置猜测，用户能直接看出每个下拉框筛选的字段和当前值。

## 方案

将筛选框统一显示为“字段：当前值”：

- 成果类型：全部 / 方案 / 模板 / SOP / Prompt / Agent / 文档
- 重点工作：全部 / 具体重点工作
- 关键任务：全部 / 当前重点工作下的具体关键任务
- 来源：全部 / AI 确认入库 / 手动登记
- 入库时间：全部 / 本周 / 本月

重点工作增加“全部”选项；关键任务根据重点工作联动，未选择重点工作时保持禁用并显示“关键任务：全部”。现有筛选状态、过滤逻辑和数据接口保持不变，仅改善显示文案与关键任务筛选的可用性。

## 验证

增加结构测试，确认筛选栏包含五个带字段名的选择器、重点工作包含“全部”选项、关键任务保留未选择重点工作时的禁用状态；运行前端结构测试和项目现有测试。
