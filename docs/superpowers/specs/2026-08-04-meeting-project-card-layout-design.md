# 会议页项目选择卡片信息布局设计

## 目标

调整会议页“请选择要查看的项目”卡片中的四项项目信息，使其横向排列，并根据内容长度分配空间。

## 方案

- 信息顺序保持不变：项目周期、项目经理、项目成员、当前进度。
- 四项信息放在同一行。
- 项目周期占最大宽度，以容纳完整时间范围。
- 项目经理占次宽，项目成员和当前进度使用较窄的固定比例。
- 卡片在窄屏下回退为两列或纵向布局，避免时间文本溢出。
- 仅修改 `frontend/src/pages/MeetingPage.tsx` 的项目选择卡片，不改变数据/API。

## 验证

- 检查前端结构测试中项目选择卡片相关断言。
- 执行前端构建，确认 TypeScript 与 Vite 构建通过。
- 在本地页面确认桌面端四项横向排列、项目周期最长，窄屏布局可读。
