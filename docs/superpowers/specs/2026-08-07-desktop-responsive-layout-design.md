# 电脑端窗口响应式布局设计

## 背景

当前前端的登录页、个人任务页和项目归档页已经包含局部响应式规则，但项目内主框架及多个核心业务页面仍按固定桌面宽度组织。窗口缩小时，固定侧栏、固定多列网格、固定详情面板和 `overflow-hidden` 组合会造成内容被压缩、裁切或无法访问。

本次改造只面向电脑浏览器窗口自由缩放，不新增手机端导航和触控交互设计。

## 目标与验收范围

- 支持浏览器内容区宽度从 800px 到超宽屏连续伸缩。
- 在 1440px、1100px、900px 和 800px 宽度下，核心页面不得出现由主布局造成的内容裁切。
- 页面整体不产生非预期横向滚动；确实需要固定列宽的业务表格在自身容器内横向滚动。
- 重要操作按钮、筛选器、详情区域在支持宽度内始终可访问。
- 保持现有业务逻辑、路由、权限和数据接口不变。
- 不改变现有宽屏视觉层级，只调整中窄窗口下的排列方式。

## 不在范围内

- 800px 以下的手机端页面。
- 手机抽屉导航、手势和触控专属交互。
- 业务页面视觉重做。
- 表格字段删减、业务功能合并或接口调整。

## 响应式策略

布局以流式尺寸为基础，使用百分比、Flexbox、CSS Grid、`minmax()` 和 `clamp()` 连续适应可用空间。断点只负责改变布局结构，不为具体设备分辨率制作固定版本。

### 宽屏：1280px 及以上

- 保持当前 176px 完整侧栏、文字菜单和用户信息。
- 仪表盘等页面维持现有多列信息密度。
- 内容宽度继续由现有最大宽度容器控制。

### 中等窗口：1024px 至 1279px

- 全局侧栏进入 64px 紧凑模式，只显示图标；菜单项通过 `title` 保留文字提示。
- 隐藏侧栏品牌文字、菜单文字、角标文字和用户文字，保留关键图标与退出入口。
- 5 至 6 列统计区域降为 3 列。
- 3 列主体区域根据内容降为 2 列。
- 固定详情面板适度收窄，但不得挤压主内容到不可用宽度。

### 窄电脑窗口：800px 至 1023px

- 延续 64px 紧凑侧栏，避免新增手机抽屉行为。
- 页面标题栏、工具栏和筛选区允许换行，操作按钮不得被裁掉。
- 统计卡、表单和详情区调整为 1 至 2 列。
- 任务管理的固定右侧详情面板改为覆盖式面板或页面内可控区域，避免与主表格并排争抢宽度；关闭方式沿用现有交互。
- 宽表格保留业务列宽，在表格滚动容器内使用横向滚动。

## 全局框架改造

`ProjectLayout` 继续使用固定视口高度，但主内容 Flex 子项必须具备 `min-width: 0` 和 `min-height: 0`，确保内部滚动区域可以正常收缩。页面级 `overflow-hidden` 只用于建立内部滚动边界，不再作为掩盖横向溢出的手段。

`Sidebar` 通过 CSS 断点在完整与紧凑两种状态间切换，不引入 JavaScript `resize` 监听。这样可以避免 resize 状态同步、重复渲染和首次加载闪烁。

## 核心页面改造

### 仪表盘

- 将无断点的 5 列、6 列统计网格改为宽屏多列、中等窗口 3 列、窄窗口 2 列。
- 将固定 3 列主体区改为宽屏 3 列、中等窗口 2 列、窄窗口单列。
- 标题栏和通知区保持可收缩，长文本使用省略或换行。

### 会议页

- 五列指标区按 5、3、2 列递减。
- 页面内容区保留纵向滚动，避免低高度窗口裁切底部内容。

### 问题页

- 六列汇总区按 6、3、2 列递减。
- 筛选栏允许换行。
- 问题列表和看板中的宽内容由局部滚动容器承载。

### 任务管理页

- 保留计划表格的固定业务列宽和内部横向滚动。
- 右侧 380px 详情区在中等窗口收窄，在 1024px 以下切换为覆盖主内容的面板。
- 标题栏、视图切换器和筛选器允许横向滚动或换行，但主要操作不能消失。

## 已有响应式页面

登录页、个人任务页、项目归档页和工作汇报页已有明确断点及局部滚动策略。本次不重写这些页面，只验证它们在新的全局侧栏和主内容尺寸下没有回归。

## 测试设计

### 自动化结构测试

- 先增加失败测试，要求全局主内容具备可收缩约束。
- 要求侧栏同时存在完整模式和 1280px 以下紧凑模式。
- 要求仪表盘、会议页和问题页的高列数网格具备响应式降列规则。
- 要求任务详情面板在 1024px 以下切换为覆盖式定位。
- 保留现有业务结构测试并运行完整前端测试集。

### 浏览器验证

在 1440×900、1100×800、900×768 和 800×720 四种视口下验证：

- 页面根节点的 `scrollWidth` 不大于 `clientWidth`，业务表格滚动容器除外。
- 侧栏在 1440px 为完整模式，在其余验证宽度为紧凑模式。
- 核心统计区域按预期降列。
- 页面主滚动区、表格滚动区和详情面板均可操作。
- 浏览器控制台无新增布局相关错误。

## 风险与约束

- 当前页面样式同时使用 Tailwind 工具类、内联样式和独立 CSS 文件。改造优先使用现有 Tailwind 断点与少量全局响应式类，避免引入新的样式框架。
- 固定业务表格不能简单压缩所有列，否则信息会不可读；此类区域必须采用局部横向滚动。
- 紧凑侧栏隐藏文字后必须为交互项保留 `title` 或等效可访问名称。
- 不修改用户工作区中已有的无关改动。
