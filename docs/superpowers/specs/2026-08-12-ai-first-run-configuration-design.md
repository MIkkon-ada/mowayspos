# AI 首次配置向导设计

## 目标

将当前“AI 能力配置”页从面向技术字段的空白配置表，重构为面向技术管理员的首次配置向导。管理员应能按顺序完成模型、API 密钥、业务能力绑定，之后再进入总览页维护已有配置。

## 用户流程

1. 从系统设置进入“AI 能力中心”。若没有可用模型，默认展示三步向导的第 1 步。
2. 第 1 步“添加模型”：填写模型显示名称、模型 ID、接口地址、模型类型和服务商标识；DeepSeek 对话模型作为默认预填模板。
3. 保存模型后自动进入第 2 步“配置 API 密钥”。密钥仅在密码输入框输入，保存后不回显。
4. 第 2 步保存密钥后调用连接测试。测试成功才可进入第 3 步；测试失败停留本步，给出可理解的失败状态和重试操作。
5. 第 3 步“启用业务能力”：为每项能力选择同类型且已配置凭证的模型。保存后，向导完成并进入 AI 能力中心总览。
6. 之后再次进入时默认显示总览：模型库、连接状态、能力绑定和维护操作；保留“添加模型”入口以启动同一向导。

## 页面与交互

### 向导框架

- 页面标题为“完成首次 AI 配置”，顶部显示“系统设置 / AI 能力中心”路径与“返回设置”。
- 三个横向步骤卡：添加模型、配置 API 密钥、启用业务能力。当前步骤使用蓝色高亮，未完成步骤为弱化状态。
- 向导每页只显示当前任务和主操作按钮；不在正式成品中显示教学旁栏、字段长说明或线框图提示文字。
- “取消”或“返回设置”不删除已保存的模型；下次可继续该流程。

### 第 1 步：添加模型

- 字段统一使用中文标签：模型显示名称、模型 ID、接口地址、模型类型、服务商标识；必填字段以红色星号标记。
- 禁止将 `code`、`display_name`、`model_name` 等内部字段名暴露为输入提示。
- 默认模型模板：DeepSeek 对话模型、`deepseek-chat`、`https://api.deepseek.com`、对话模型、`deepseek`。
- “保存并继续”创建模型后进入第 2 步；后端字段仍使用既有 `AIModelWrite` 契约映射提交。

### 第 2 步：配置 API 密钥

- 标题显示当前模型的显示名称；输入框为 `password` 类型。
- 主操作为“保存并测试连接”。先调用凭证保存接口，再调用模型测试接口。
- 成功：展示成功状态并启用“继续启用能力”。失败：展示“连接失败，请检查 API Key、模型 ID 与接口地址”，允许更改密钥和重试；不显示原始密钥或服务端异常文本。
- 测试操作只对当前后端支持的对话模型开放；语音模型进入总览中的模型维护流程，避免在首次对话模型向导中产生错误承诺。

### 第 3 步：启用业务能力

- 展示会议纪要分析、任务提取、项目初始化分析和语音实时转写。
- 仅提供类型匹配、已启用、已配置凭证的模型选项：前三项使用对话模型，实时转写使用语音模型。
- 用户可暂不绑定不具备同类型模型的能力；完成后在总览中显示为“未启用”。
- 保存时复用 `saveAICapabilityPolicy`，设置主模型和启用状态。

### 总览页

- 首次向导完成后显示“AI 能力中心”总览，聚合模型数、凭证状态和已启用能力数。
- 模型列表可继续执行：添加模型、更新凭证、测试连接、启用/停用。
- 能力绑定列表保持现有能力策略功能，但使用中文名称与清楚的状态文案。
- 加载失败不再仅显示“加载 AI 能力配置失败”：提供“重新加载”按钮；保留原始技术错误仅供控制台记录。

## 数据与接口边界

- 不修改现有数据库模型或迁移。
- 使用既有前端 API：`listAIModels`、`createAIModel`、`replaceAIModelCredentials`、`testAIModel`、`listAICapabilityPolicies`、`saveAICapabilityPolicy`。
- 后端继续通过 `/api/ai-config/*` 管理模型、加密凭证与能力策略；浏览器仅接收 `credential_configured` 状态，绝不接收或回显 API Key。
- 首次配置状态从已加载模型和策略推导，不新增持久化的“向导已完成”标志：没有可用模型时进入第 1 步；存在模型但无凭证时恢复第 2 步；存在可测试模型但能力未绑定时进入第 3 步。

## 错误处理

- 加载失败：页面显示简短说明和“重新加载”，保留前一次已加载数据（如有）。
- 字段校验失败：在对应字段附近显示服务端返回的可读校验信息。
- 凭证保存、连接测试、策略保存失败：不推进向导步骤，不清空用户刚输入的非敏感模型字段；API Key 输入框遵循安全规则不回显。
- 403：显示“仅技术管理员可以配置 AI 能力”。
- 503（加密密钥未配置）：显示“AI 配置服务暂不可用，请联系系统管理员”，不显示内部环境变量名称。

## 验收与测试

- 前端组件测试覆盖：首次空状态进入第 1 步、默认 DeepSeek 模板、保存后进入密钥步骤、连接成功/失败、只显示类型匹配的能力绑定选项、加载失败重试。
- API 契约测试覆盖：模型创建、凭证替换、模型测试和策略保存仍使用现有端点与字段。
- 安全回归：任何成功、失败或编辑状态均不得在 DOM、请求后状态或错误提示中回显 API Key。
- 手动视觉验收：与已确认的成品视觉一致——简洁白色卡片、三步顶部导航、中文字段、统一 SVG 下拉箭头、无冗长说明文案。
