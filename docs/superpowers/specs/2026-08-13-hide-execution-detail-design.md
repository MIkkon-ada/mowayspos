# 暂时隐藏执行详情页设计

## 目标

暂时隐藏工作推进表中的“执行详情”入口，并阻止用户通过关键任务点击进入该视图；执行详情组件及其实现保留，便于后续恢复。

## 方案

在 `frontend/src/pages/TaskManagementPage.tsx` 中增加一个临时显示开关。开关关闭时：

- 不渲染“执行详情”视图切换按钮。
- 页面保持“表格视图”为默认和唯一可进入的视图。
- 关键任务点击继续使用当前工作推进表的右侧详情面板，不切换 `viewMode`。
- 执行详情视图的渲染分支增加保护，避免其他状态路径绕过入口。

不删除 `KeyTaskExecutionDetailView`、执行详情相关 API 或组件代码。

## 验证

更新前端源码测试，覆盖以下行为：

1. “执行详情”按钮在临时隐藏期间不渲染。
2. 页面默认仍使用“表格视图”。
3. 关键任务详情入口不会把页面切换到执行详情视图。
4. 原有表格视图和右侧详情面板相关断言继续通过。
