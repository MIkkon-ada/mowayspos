# 项目方案填写右侧工作区

## 目标

将项目负责人填写方案从居中的弹窗式容器改为右侧全高工作区，消除四周留白、圆角和浮层阴影，使填写任务成为项目页中的主工作区域。

## 布局

- 应用左侧导航保持不变；项目方案页面占据导航右侧的全部可用宽度和高度。
- 工作区不再设置最大宽度、外部边距、圆角、边框或浮层阴影。
- 页头和提交操作栏保持在工作区内固定；重点工作与关键任务区域在两者之间独立滚动。
- 小屏幕继续以单列方式呈现，不引入横向页面滚动。

## 行为与兼容性

- 返回和取消仍回到项目详情页；提交成功后的去向不变。
- 负责人权限、项目状态校验、AI 草稿、任务编辑及提交接口均不改变。
- 仅调整项目负责人填写方案路由的外层容器及工作台视觉容器；其他页面与已有弹窗不受影响。

## 验证

- 为页面容器增加结构测试，确保不再存在居中最大宽度的弹窗壳，并保留右侧工作区的全高与溢出控制。
- 运行现有 Owner Submit 前端单测、结构检查及生产构建。
