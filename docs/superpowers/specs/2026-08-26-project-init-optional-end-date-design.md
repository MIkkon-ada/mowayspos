# 项目立项结束日期待定选项

## 目标

在项目立项弹窗的结束日期控件下方提供一个轻量的“暂不填写”选择入口，并明确企业教练为必填团队角色。

## 交互

- 结束日期输入框保持原位；其下方居中显示带圆形选择符号的“暂不填写”。
- 选择后清空并禁用结束日期输入框，选择符号进入选中状态；再次选择后恢复输入。
- 表单提交时“暂不填写”仅传递空的 `end_date`，不增加新的后端字段或改变其他日期规则。

## 必填提示

- 企业教练标题增加红色星号，与项目负责人并列标识为必填。
- 创建与编辑共用同一团队角色标题逻辑，确保桌面及窄屏布局均一致。

## 范围

- 仅修改 `ProjectInitModal` 中的新建/编辑项目表单及其前端结构测试。
- 不修改项目负责人方案填写页、项目下发校验或后端数据库结构。
