# 项目团队成员标签布局设计

## 目标

将项目立项/编辑页面中各角色的已选人员，从“每人占一整行”改为紧凑的姓名标签布局：同一行尽量并排显示多个姓名，空间不足时自动换行。

## 范围

- 仅修改 `frontend/src/features/settings/ProjectInitModal.tsx` 的前端展示。
- 项目负责人、企业教练、统筹人、协同成员统一使用姓名标签展示。
- 标签显示完整姓名，不生成姓名首字头像。
- 每个标签保留独立的移除按钮。
- 空角色继续显示“未配置”和添加入口。

## 不变项

- 不修改后端接口、请求参数、数据结构或保存逻辑。
- 不修改人员搜索、筛选、勾选、互斥选择和角色分配逻辑。
- 不改变下拉选人弹窗的交互，仅保持其现有姓名列表展示。

## 视觉与交互

- 使用 `flex-wrap` 标签容器，标签采用紧凑边框、浅色背景和圆角。
- 标签宽度由姓名内容决定；容器宽度不足时换行。
- 移除按钮放在姓名右侧，点击仍调用现有移除成员逻辑。
- 标签区域保留合理的最小高度，避免空角色卡片跳动。

## 验证

- 增加静态布局回归测试，确认已选成员使用可换行标签容器且不渲染头像块。
- 运行前端单元测试和生产构建。
- 在本地浏览器检查单人、多人和换行场景。
