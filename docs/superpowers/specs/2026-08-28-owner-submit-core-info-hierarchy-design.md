# 负责人填报项目核心信息层级设计

## 目标

让负责人填报页“项目核心信息”卡片中的字段标题、字段内容和未填写状态具有明确的视觉区分，降低快速浏览时的认知负担。

## 方案

保留现有字段和布局，只建立三层阅读层级：

1. 字段标题使用更小、更浅、带字距的标签样式。
2. 已填写内容使用更深的正文色；项目名称保持最醒目的标题层级。
3. 项目完成准则 / 验收标准的内容置于浅色、带边框的内容区，并在内容区上方标注“内容”。空值改为低对比的“未填写”状态标签，避免与真实内容混淆。

项目周期继续保留日历图标，但日期作为独立正文行呈现。

## 范围

仅调整 `OwnerSubmitModal` 的只读项目核心信息卡片和对应前端结构测试；不改字段、接口、权限、表单输入或工作推进方案。

## 回归测试

测试将验证：标签与正文使用不同的样式令牌；验收标准具有独立内容容器和内容提示；原有项目名称、周期、完成准则和补充详情均继续存在。
