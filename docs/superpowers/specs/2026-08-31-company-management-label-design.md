# 公司管理展示名称替换设计

## 目标

将系统中所有面向用户的“CEO”“公司 CEO”“公司CEO”业务文案统一调整为“公司管理”。

## 范围

- 前端页面、导航、提示、按钮、状态、表单与导出内容中的相关文案。
- 后端返回给用户的错误提示、标签和可见说明。
- 项目内文档、README、验收清单和测试计划中的业务角色说明。
- “需 CEO 决策”“CEO 批示”“转 CEO”等流程文案，分别改为“需公司管理决策”“公司管理批示”“转公司管理”。

## 保持不变

- 数据库存储值和代码技术键：`company_ceo`、`project_ceo`、`ceo_note`、`is_ceo` 等。
- 现有 API 路径、请求字段和历史数据。
- 项目内“企业教练”的名称与职责；它不是本次改名的对象。
- 权限能力和角色边界：公司管理仍保有原公司 CEO 的全局查看与项目入口配置能力。

## 实现边界

仅在展示层和说明层替换术语，不迁移数据、不改接口契约，也不改变权限判断。测试中用于断言用户可见文案的预期会同步更新；用作内部账号、字段名或技术键的 `ceo` 保留。

## 验证

执行针对角色标签、仪表盘权限、确认流程和项目生命周期的现有测试，并通过全文检索确认产品源码和用户文档不再保留旧展示名称；排除技术键、API 名称、数据库字段和历史备份。
