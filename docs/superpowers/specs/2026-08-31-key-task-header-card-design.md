# 关键任务顶部卡片轻量视觉调整

## 目标

让关键任务执行工作台的顶部信息区更贴近参考图的卡片质感，同时保持现有信息、权限和操作行为不变。

## 范围

- 保留工作台上方的“返回”入口。
- 将 `KeyTaskHeader` 从横向浅蓝底栏调整为白底、圆角、细边框的独立信息卡；保留轻微阴影。
- 保持面包屑、任务标题、状态、风险提示、负责人、协同人、计划时间与现有操作按钮的顺序、内容和数据来源不变。
- 保持所有按钮的权限条件和现有事件处理不变。

## 非目标

- 不增加任务图标或新的字段。
- 不重排下方的当前进展、任务计划、成果、问题、推进记录或所属关系区域。
- 不修改接口、数据结构、状态值或权限逻辑。

## 验证

- 更新顶部结构测试，明确要求白色卡片、圆角和边框样式。
- 先运行该测试确认它在现状失败；完成样式调整后重新运行，并执行前端构建检查。
