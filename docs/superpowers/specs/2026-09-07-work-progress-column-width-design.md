# 工作推进表重点工作列宽调整设计

## 目标

收窄工作推进表的“重点工作”列，减少合并单元格中的横向留白，同时将释放的空间交给“关键任务”列，提升任务标题的可读性。

## 方案

- 使用比例列宽保证 100% 视角下布局稳定：重点工作 14%、关键任务 23%、负责人 6%、计划时间 9%、协同人 11%、最新已确认提交 18.5%、下一步 18.5%。
- 在最右侧新增“下一步”列，展示最近一次已确认推进记录的下一步内容。
- 表格最小宽度设为 1120px，窄屏时允许横向滚动，负责人、计划时间、协同人和提交信息不会被压缩到不可读。
- 不修改数据、交互、滚动行为、sticky 列或响应式规则。

## 验收标准

- 第一列明显比当前更紧凑。
- 关键任务标题获得更多横向空间，长标题更少换行。
- 负责人、计划时间、协同人、最新提交列的位置和宽度保持不变。
