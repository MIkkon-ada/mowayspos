# 负责人补充立项参考稿样式设计

## 目标

将负责人补充立项页面统一为参考 HTML/截图中的项目工作台视觉：顶部项目标题区、左侧项目概览、中间重点工作导航、右侧工作推进详情，以及固定底部操作栏。此次只调整呈现层，不改变现有数据流、API、权限判断、AI 草稿合并和提交审核行为。

## 视觉结构

- 页面使用浅灰蓝背景和白色内容卡，建立清晰的工作区层次。
- 顶部标题区保持 88px 左右高度，标题、状态标签和返回按钮对齐。
- 桌面端主体采用左侧 360px 项目概览 + 右侧工作推进区域；工作推进区域内部为约 228px 导航栏 + 自适应详情区。
- 详情区使用较大的留白和细边框，目标、验收标准、推进流程、计划时间和关键任务依次排列。
- AI 分析面板与主工作台共用圆角、边框、阴影和间距体系；AI 操作使用紫色强调，提交审核使用橙色强调。
- 底部操作栏固定在工作台底部，页面滚动内容预留安全间距。
- 1024px 以下自动切换为单列布局，保证表格和操作仍可访问。

## 交互约束

- 所有现有按钮、输入框、人员选择器、任务新增/删除、AI 上传/分析/合并和提交逻辑保持不变。
- 待审核等不可编辑状态继续通过现有 `fieldset` 只读机制呈现，并保留状态提示。
- 新增语义 class 和测试标记仅用于样式与回归测试，不作为业务状态判断依据。

## 验收标准

1. 页面具有明确的顶部、概览、重点工作导航、详情和底部操作区域。
2. 页面在桌面端与参考稿的比例、卡片层次、颜色强调、间距和固定操作栏一致。
3. AI 面板与主工作台视觉统一，上传/分析/预览/失败状态仍可正常表达。
4. 待审核页面仍然只读，提交按钮和编辑操作不可用。
5. 现有前端单元测试、合同测试和构建全部通过。
