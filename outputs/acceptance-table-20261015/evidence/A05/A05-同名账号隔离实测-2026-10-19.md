# A05 同名不同人员 ID 隔离账号实测补充（2026-10-19）

## 环境和数据

测试在 `.runtime/acceptance-20261019/moways-uat.sqlite` 隔离数据库与本地 V2 API 上完成，没有修改主业务数据库。创建两个独立合成账号 `uat_member` 与 `uat_member_same_name`；两者显示名称相同，但分别映射到人员 ID 4 和 7。两人都是隔离项目 1 的项目成员。项目中已有一项关键任务，`assignee_id` 明确绑定人员 ID 4。

## 实际账号请求

两个账号分别通过 `/api/auth/login` 登录（均 HTTP 200），随后分别调用 `/api/updates/voice-context?project_id=1`（均 HTTP 200）。ID 4 账号只收到分配给自己的关键任务；同名 ID 7 账号收到空列表。系统没有仅凭显示名称把 ID 4 的任务暴露给 ID 7。

## 验收边界

这验证了本地隔离环境中账号登录、同名不同 ID 的任务上下文隔离。没有核对真实组织账号改名、历史空 ID/重名记录、跨项目身份映射和目标数据库，因此 A05 继续保持“未验收”。
