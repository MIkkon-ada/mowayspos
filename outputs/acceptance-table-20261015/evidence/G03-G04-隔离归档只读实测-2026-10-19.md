# G03 / G04 隔离环境结项归档与只读复核（2026-10-19）

## 项目状态与操作

隔离项目 1 完成一次合成汇报确认、问题解决及负责人任务状态更新后，负责人提交结束申请（HTTP 201，项目进入 `pending_close`），教练审批（HTTP 200，项目进入 `ended`），技术管理员归档（HTTP 200，项目进入 `archived`）。普通负责人再次调用归档接口返回 403。非项目成员隔离账号对项目详情读取返回 403。

## 归档后历史与写入边界

成员账号直接打开本地 V2 项目链接 `/work/tasks?projectId=1`，工作推进表仍显示已完成任务、最新进展及下一步记录；进入任务详情可见原提交、确认人、关联成果、已解决问题和推进时间线。归档后成员读取项目详情/执行工作台均返回 200；成员任务状态写请求返回 403；普通负责人不能归档。修复后执行工作台返回 `can_view=true`，而操作、结构编辑、计划、汇报、完成、重开、风险权限均为 false；页面隐藏对应写入按钮。

## 修复与验证

实际状态更新曾触发 `AttributeError: 'SubTask' object has no attribute 'edit_count'` 并返回 500。现已删除不存在字段的引用，状态时间线使用同一次 UTC 事件时间生成去重键，并记录人员 ID。复测负责人更新关键任务状态返回 HTTP 200，生成“未开始→已完成”事件，页面状态同步。窄回归命令 `pytest tests/test_key_task_execution_workspace.py::test_patch_subtask_status_updates_state_and_execution_timeline tests/test_key_task_execution_workspace.py::test_frozen_key_task_workspace_exposes_history_without_write_actions -q` 结果 4 passed（冻结状态参数覆盖 `pending_close`、`ended`、`archived`）。
